Telepítés és indítás

A RocKIT asztali alkalmazásként fut. Mindig az operációs rendszerének megfelelő legfrissebb telepítőt vagy alkalmazáscsomagot használja.

Telepítés Windows rendszeren​

Windows rendszeren töltse le és futtassa a legfrissebb RocKIT - RO-Crate Kit Setup *.exe telepítőt. A telepítő automatikusan végigfut, parancsikont hoz létre az asztalon, és a RocKIT ezután a parancsikonnal vagy a Windows alkalmazásmenüjéből indítható.

A telepített alkalmazás nagy méretű lehet, ezért a telepítés előtt ellenőrizze, hogy rendelkezésre áll-e elegendő szabad tárhely.

Telepítés Linux rendszeren​

Linux rendszeren az AppImage csomag a legegyszerűbb választás, mert nem igényel telepítést. Töltse le a legfrissebb RocKIT - RO-Crate Kit-*.AppImage fájlt, majd abban a könyvtárban, ahová letöltötte, futtassa:

chmod +x ./RocKIT*.AppImage
./RocKIT*.AppImage

Ha az AppImage nem indul el, mert hiányzik a FUSE támogatás, Ubuntu és Linux Mint alapú rendszereken telepítse a szükséges csomagot:

sudo apt update
sudo apt install -y libfuse2

Ezután futtassa újra az AppImage fájlt.

Alternatívaként telepíthető a legfrissebb .deb csomag is:

sudo apt install ./RocKIT*.deb

A .deb csomag telepítése után a RocKIT elindítható az alkalmazásmenüből RocKIT - RO-Crate Kit néven, vagy parancssorból az alkalmazáscsomag által biztosított paranccsal.

Linux Mint és Ubuntu alapú rendszereken az AppImage használata ajánlott. A .deb csomagot akkor válassza, ha telepített alkalmazásként szeretné használni a RocKIT-et.

Telepítés macOS rendszeren​

macOS rendszeren töltse le és nyissa meg a legfrissebb RocKIT - RO-Crate Kit-*.dmg fájlt. Húzza a RocKIT.app alkalmazást az Applications mappába, vagy abba a mappába, ahol az alkalmazást tárolni szeretné.

Frissítés​

Új verzió telepítéséhez általában nem szükséges először eltávolítani a korábbi verziót. Töltse le az operációs rendszerének megfelelő új telepítőt vagy alkalmazáscsomagot, majd telepítse a meglévő verzió fölé.

  • Windows rendszeren futtassa az új .exe telepítőt, és kövesse a telepítő lépéseit.
  • macOS rendszeren nyissa meg az új .dmg fájlt, majd húzza az alkalmazást az Applications mappába. Ha a rendszer rákérdez, válassza a meglévő alkalmazás cseréjét.
  • Linux rendszeren .deb csomag esetén telepítse az új csomagot a szokásos módon. AppImage használata esetén cserélje le a korábbi AppImage fájlt az új verzióra.

A frissítés után indítsa újra az alkalmazást. A korábbi beállítások és munkafájlok normál esetben megmaradnak.

Első indítás utáni beállítások​

A RocKIT felülete több nyelven is használható. A megjelenítési nyelvet a Fájl > Beállítások > Megjelenítési nyelv beállítása menüpontban lehet kiválasztani.

A RocKIT az első indításkor automatikusan létrehozza az alapértelmezett ARP Production CEDAR profilszolgáltatót. Ezt a Metadataprofil-kezelő felületén, az RO-Crate > Metadataprofil-kezelő menüpontban lehet ellenőrizni vagy módosítani; a szolgáltatók listája a Szolgáltatók beállítása ikonnal nyitható meg.

Repozitóriumi exportáláshoz az Adatrepozitórium-kezelő felületén ARP Dataverse, általános Dataverse vagy Zenodo típusú repozitóriumot is beállíthat. Az ARP Dataverse a RocKIT fő támogatott repozitóriumi platformja; ehhez nyissa meg az RO-Crate > Adatrepozitórium-kezelő menüpontot, majd a Repozitórium hozzáadása gombbal adja meg az adatrepozitórium eléréséhez szükséges adatokat.

Indítás és munkaterület megnyitása​

Az alkalmazás megnyitásakor a RocKIT nyitóképernyőt jelenít meg a munkafelület indulása közben. Ezután megjelenik az alkalmazás főablaka. Ha még nincs megnyitott mappa, a munkaterület üres, és az RO-Crate-panelek nem tudnak adatcsomag-tartalmat megjeleníteni.

Innen általában háromféleképpen folytathatja:

  • Hozzon létre új RO-Crate-et egy fájlokat tartalmazó mappából. Lásd: Gyors kezdés: RO-Crate létrehozása az alapoktól.
  • Nyisson meg egy meglévő RO-Crate-et, és folytassa annak szerkesztését. Lásd: Gyors kezdés: meglévő RO-Crate megnyitása és szerkesztése.
  • Importáljon adatcsomagot távoli repozitóriumból. Lásd: Gyors kezdés: adatcsomag importálása távoli repozitóriumból.

A használni kívánt mappát a Fájl > Mappa megnyitása RO-Crate-ként menüponttal vagy a Theia megfelelő munkaterületi parancsával válassza ki. A mappa megnyitása után a RocKIT inicializálja a munkaterület RO-Crate-nézeteit. A mappa tartalmától függően betölt egy meglévő adatcsomagot, vagy felajánlja egy új létrehozását.

Ha bezárja a munkaterületet, vagy mappa megnyitása nélkül indítja el az alkalmazást, a menük és a munkafelület továbbra is használhatók, de egy munkaterületmappa megnyitásáig nincs szerkeszthető aktív RO-Crate.
