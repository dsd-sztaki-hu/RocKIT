Installation and Startup

RocKIT runs as a desktop application. Always use the latest installer or application package for your operating system.

Installation on Windows​

On Windows, download and run the latest RocKIT - RO-Crate Kit Setup *.exe installer. The installer runs automatically, creates a desktop shortcut, and RocKIT can then be started from the shortcut or from the Windows application menu.

The installed application can be large, so check that enough free disk space is available before installation.

Installation on Linux​

On Linux, the AppImage package is the simplest option because it does not require installation. Download the latest RocKIT - RO-Crate Kit-*.AppImage file, then run the following commands in the directory where you downloaded it:

chmod +x ./RocKIT*.AppImage
./RocKIT*.AppImage

If the AppImage does not start because FUSE support is missing, install the required package on Ubuntu and Linux Mint based systems:

sudo apt update
sudo apt install -y libfuse2

Then run the AppImage file again.

Alternatively, you can install the latest .deb package:

sudo apt install ./RocKIT*.deb

After installing the .deb package, RocKIT can be started from the application menu as RocKIT - RO-Crate Kit, or from the command line with the command provided by the application package.

On Linux Mint and Ubuntu based systems, the AppImage package is recommended. Choose the .deb package if you want to use RocKIT as an installed application.

Installation on macOS​

On macOS, download and open the latest RocKIT - RO-Crate Kit-*.dmg file. Drag RocKIT.app to the Applications folder, or to the folder where you want to keep the application.

Updating​

To install a new version, you usually do not need to remove the previous version first. Download the new installer or application package for your operating system, then install it over the existing version.

  • On Windows, run the new .exe installer and follow the installer steps.
  • On macOS, open the new .dmg file, then drag the application to the Applications folder. If the system asks, choose to replace the existing application.
  • On Linux, install the new package in the usual way when using a .deb package. When using AppImage, replace the earlier AppImage file with the new version.

After updating, restart the application. Existing settings and workspace files are normally preserved.

First-Run Configuration​

RocKIT's interface is available in multiple languages. Choose the display language from File > Preferences > Configure Display Language.

On first startup, RocKIT automatically creates the default ARP Production CEDAR profile provider. You can review or modify it in Metadata Profile Manager, available from RO-Crate > Metadata Profile Manager; open the provider list with the Configure Providers icon.

For repository export, you can configure an ARP Dataverse, generic Dataverse, or Zenodo repository in Data Repository Manager. ARP Dataverse is RocKIT's main supported repository platform; for that setup, open RO-Crate > Data Repository Manager, then use + Add Repository to enter the connection details for the data repository.

Recommended values:

FieldValue
NameAny display name.
Base URLhttps://repo.researchdata.hu
API TokenThe user's API token generated in the repository interface.

Startup and Workspace Opening​

When the application opens, RocKIT shows a splash screen while the workbench starts. After startup, the main application window appears. If no folder is open yet, the workspace is empty and the RO-Crate panels have no crate content to display.

From this point you normally choose one of three starting paths:

  • Create a new RO-Crate from a folder of files. See Quick Start: Create an RO-Crate from Scratch.
  • Open and continue editing an existing RO-Crate. See Quick Start: Open and Edit an Existing RO-Crate.
  • Import a dataset from a remote repository. See Quick Start: Import a Dataset from a Remote Repository.

Use File > Open Folder or the equivalent Theia workspace command to choose the folder you want to work with. Once a folder is open, RocKIT initializes the RO-Crate views for that workspace. Depending on the folder contents, it may load an existing crate or offer options for creating one.

If you close the workspace or start the application without opening a folder, you can still use the menus and workbench, but there is no active RO-Crate to edit until you open a workspace folder.
