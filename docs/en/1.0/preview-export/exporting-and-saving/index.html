Exporting and Saving

Saving and exporting are separate actions.

Save RO-Crate writes the current metadata to ro-crate-metadata.json in the workspace root and regenerates ro-crate-preview.html. It also persists RocKIT ignore rules in .rockit/ignored.txt when ignore rules are available.

Use File > Package RO-Crate to create a ZIP package from the open workspace. In the dialog, select the package type, choose whether external files should be included, then click Package and select the destination of the ZIP file.

Packaging cannot start while the RO-Crate metadata contains unsaved changes. Use Save in the dialog to save them; after a successful save, the Package button becomes available.

Export Modes​

Normal Package adds the complete workspace to the ZIP, except for items excluded by ignore rules. It always includes ro-crate-metadata.json and ro-crate-preview.html, even if an ignore rule would otherwise exclude them. Its default filename is <workspace>.zip.

Clean RO-Crate Package contains ro-crate-metadata.json, the existing ro-crate-preview.html, and available workspace files referenced as files by the metadata. Other workspace files and RocKIT technical files are omitted. This mode requires a ro-crate-metadata.json file that RocKIT can parse successfully. Its default filename is <workspace>-clean.zip.

Including Files Outside the Workspace​

Include referenced local files that are outside the RO-Crate folder is cleared by default. When selected, RocKIT looks for locally resolvable files referenced by the RO-Crate metadata but stored outside the workspace folder and adds copies to the ZIP. These files are placed under imported_resources; if names collide, RocKIT selects a unique directory or filename. The option applies only to readable files referenced by the metadata: it does not add arbitrary external files, directories, or unresolved references.

When the checkbox is cleared, local files outside the workspace are not included. The option is available for both normal and clean packages.

Ignore Rules​

RocKIT reads ignore rules from .rockit/ignored.txt and combines them with default ignored entries. Rules are normalized to workspace-relative paths. Negated rules can re-include a path. Ignore rules apply to both package types.

After packaging, inspect the ZIP before uploading or distributing it. Check that ro-crate-metadata.json and the expected payload files are present and, when external files were included, inspect the contents of imported_resources.
