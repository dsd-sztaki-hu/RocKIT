# Agent Launcher

Provides RocKIT commands and UI for launching supported coding agents from the
Electron Theia application.

The extension prepares agent workspaces, opens integrated terminals, manages
RocKIT agent instructions, and helps configure the RO-Crate MCP server for
supported agent runtimes.

## Development

```bash
yarn build
yarn test
```
