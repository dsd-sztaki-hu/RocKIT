# Data Sources

Provides RocKIT data source registration for Theia extensions.

The extension contributes an "Add New Data Source" command and stores selected
folder URIs in Theia workspace storage so other RocKIT extensions can access the
configured data source roots.

## Development

```bash
yarn build
```
