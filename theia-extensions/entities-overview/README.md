# Entities Overview

Provides the RocKIT entities overview view for browsing and managing RO-Crate
entities inside the Theia application.

The extension contributes a tree-based side panel with filtering, expansion,
selection, edit, delete, and documentation actions for entities loaded through
the shared RocKIT application state.

## Development

```bash
yarn build
```
