# file-preview

## Description

RocKIT file preview extension.

This workspace package is derived from the Eclipse Theia `@theia/property-view`
extension. It keeps a RocKIT-specific package identity while preserving the
upstream property-view structure used by the Theia extension runtime.

This package adapts the upstream property view into a RocKIT file preview view.

## Upstream

- Package: `@theia/property-view`
- Base version: `1.65.2`
- Repository: <https://github.com/eclipse-theia/theia>
- Source path: `packages/property-view`
