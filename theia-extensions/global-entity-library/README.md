# Global Entity Library

RocKIT widget for viewing and maintaining reusable entities stored in the
application-level `ROCKIT_ROOT_PATH/global-entities.json` file.

## Usage

Open **RO-Crate → Global Entity Library**. Records can be searched, added,
edited, and deleted. The widget follows the same Ant Design and Theia theme
integration as RocKIT's other manager tables.
