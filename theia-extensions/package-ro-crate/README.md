# Package RO-Crate

Provides RocKIT packaging for exporting the open RO-Crate workspace as a ZIP
archive.

The extension contributes the **Package RO-Crate** command and dialog in the
File menu. It supports normal packaging for the full workspace and clean
packaging for an RO-Crate-focused export.

## Development

```bash
yarn build
```
