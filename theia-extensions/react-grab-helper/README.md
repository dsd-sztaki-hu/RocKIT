# React Grab Helper

Provides a RocKIT development helper for enabling React Grab in Theia.

The extension contributes the `rockit.developer.reactGrab.enabled` preference.
When RocKIT runs in development mode and this preference is enabled, the
extension initializes React Grab to help inspect and select React components
during frontend development.

## Development

```bash
yarn build
```
