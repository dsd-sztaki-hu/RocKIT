# RO-Crate Preview

Provides a RocKIT dialog for previewing the current RO-Crate JSON from
application state.

The extension contributes the **RO-Crate Preview** command to the File menu. The
preview displays the active RO-Crate metadata as formatted JSON, supports
copying the JSON to the clipboard, and links to the RocKIT preview
documentation.

## Development

```bash
yarn build
yarn test
```
