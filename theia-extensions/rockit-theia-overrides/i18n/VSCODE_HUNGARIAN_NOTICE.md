# Hungarian VS Code translations

`vscode.hu.json` contains Hungarian strings selected from Microsoft's
**Hungarian Language Pack for Visual Studio Code**, version 1.48.3.

Source: https://marketplace.visualstudio.com/items?itemName=MS-CEINTL.vscode-language-pack-hu

The upstream strings are distributed under the MIT License. Entries are matched
to the version of VS Code localization metadata used by the current Theia
dependency, first by their localization key and then by identical English source
text. RockIT-specific wording in `nls.hu.json` is loaded afterwards and therefore
takes precedence.
