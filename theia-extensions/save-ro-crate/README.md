# Save RO-Crate

Provides RocKIT save commands and persistence services for RO-Crate workspaces.

The extension contributes the **Save RO-Crate** command and integrates with
Theia's save handling. It writes `ro-crate-metadata.json`, generates
`ro-crate-preview.html`, persists `.rockit` ignored rules, and coordinates
application state updates while saving.

## Development

```bash
yarn build
```
